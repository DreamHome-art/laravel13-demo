## 关于 Laravel

Laravel 是一个具有表现力、优雅语法的 Web 应用框架。我们坚信，开发必须是一种令人愉悦且富有创造力的体验，才能真正令人感到满足。Laravel 通过简化许多 Web 项目中常见的任务来减轻开发负担，例如：

- [简洁、快速的路由引擎](https://laravel.com/docs/routing)。
- [强大的依赖注入容器](https://laravel.com/docs/container)。
- 支持 [Session](https://laravel.com/docs/session) 和 [缓存](https://laravel.com/docs/cache) 存储的多种后端。
- 表现力强、直观的 [数据库 ORM](https://laravel.com/docs/eloquent)。
- 与数据库无关的 [Schema 迁移](https://laravel.com/docs/migrations)。
- [健壮的后台任务处理](https://laravel.com/docs/queues)。
- [实时事件广播](https://laravel.com/docs/broadcasting)。

Laravel 易于上手、功能强大，并提供了构建大型、健壮应用所需的工具。

## 学习 Laravel

Laravel 拥有所有现代 Web 应用框架中最详尽、最全面的 [文档](https://laravel.com/docs) 和视频教程库，让你能轻松上手该框架。

此外，[Laracasts](https://laracasts.com) 包含数千个视频教程，涵盖 Laravel、现代 PHP、单元测试和 JavaScript 等众多主题。通过深入学习我们丰富的视频库来提升你的技能。

你还可以在 [Laravel Learn](https://laravel.com/learn) 上观看结合真实项目的短小课程，在这些课程中，你将一边学习 PHP 基础，一边被引导从零开始构建一个 Laravel 应用。

## 智能体开发

Laravel 可预测的结构和约定使其非常适合 AI 编程智能体，例如 Claude Code、Cursor 和 GitHub Copilot。安装 [Laravel Boost](https://laravel.com/docs/ai) 来增强你的 AI 工作流：

```bash
composer require laravel/boost --dev

php artisan boost:install
```

Boost 为你的智能体提供 15+ 个工具和技能，帮助智能体在遵循最佳实践的同时构建 Laravel 应用。
